Cómo Conectar OpenClaw a WhatsApp y Telegram: Tutorial 2026

Tutorial paso a paso para configurar OpenClaw con WhatsApp y Telegram. Tené a Claude respondiendo en tus chats.

Claude en tu WhatsApp

¿Te imaginás preguntarle algo a Claude directamente desde WhatsApp? Con OpenClaw es posible. En este tutorial te muestro cómo configurarlo paso a paso.

Si todavía no conocés OpenClaw, empezá por nuestra guía completa de OpenClaw.

Requisitos Previos

  • OpenClaw instalado (npm install -g openclaw@latest)
  • API key de Claude o proxy como APIYI
  • Node.js 22+
  • Computadora encendida (o VPS)

Si no tenés API key, podés conseguir una siguiendo nuestro tutorial de Claude API.

Parte 1: Configurar WhatsApp

Paso 1: Iniciar el Login

openclaw channels login whatsapp

Esto inicia el proceso de vinculación con WhatsApp Web.

Paso 2: Escanear el QR

Verás un código QR en la terminal. En tu celular:

  1. Abrí WhatsApp
  2. Configuración > Dispositivos vinculados
  3. Vincular dispositivo
  4. Escaneá el QR

Paso 3: Verificar Conexión

openclaw status

Deberías ver: whatsapp: connected

Paso 4: Configurar Acceso

MUY IMPORTANTE: Limitá quién puede usar tu bot. Editá ~/.openclaw/openclaw.json:

{\n  "channels": {\n    "whatsapp": {\n      "enabled": true,\n      "allowFrom": [\n        "+54911XXXXXXXX",\n        "+5491XXXXXXXXX"\n      ]\n    }\n  }\n}

Solo los números en allowFrom podrán hablar con el bot.

Paso 5: Probar

Enviá un mensaje desde tu WhatsApp al número vinculado:

Hola, ¿funcionás?

Deberías recibir respuesta de Claude.

Parte 2: Configurar Telegram

Paso 1: Crear Bot con BotFather

En Telegram, buscá @BotFather y enviá:

/newbot

Te pedirá:

  • Nombre: Mi Asistente Claude
  • Username: mi_claude_asistente_bot (debe terminar en _bot)

BotFather te dará un token. Guardalo.

Paso 2: Configurar en OpenClaw

openclaw configure --section channels.telegram

Ingresá el token cuando te lo pida.

O editá directamente ~/.openclaw/openclaw.json:

{\n  "channels": {\n    "telegram": {\n      "enabled": true,\n      "token": "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"\n    }\n  }\n}

Paso 3: Iniciar el Canal

openclaw channels start telegram

Paso 4: Probar

Buscá tu bot en Telegram y enviá:

/start\nHola, ¿cómo estás?

Configuración Avanzada

Modo Grupos

Por defecto, en grupos el bot solo responde cuando lo mencionás. Podés cambiarlo:

{\n  "channels": {\n    "telegram": {\n      "requireMention": true,\n      "mentionTriggers": ["@mi_bot", "claude", "bot"]\n    }\n  }\n}

Límite de Mensajes

Para controlar costos, podés limitar mensajes por usuario:

{\n  "limits": {\n    "messagesPerDay": 50,\n    "tokensPerMessage": 4000\n  }\n}

Revisá nuestra guía de precios de APIs para calcular tus costos.

Respuestas en Streaming

Para que las respuestas aparezcan mientras se generan:

{\n  "streaming": {\n    "enabled": true,\n    "chunkSize": 100\n  }\n}

Usar APIYI como Proxy

Si no tenés tarjeta internacional para la API de Anthropic, tenemos una guía completa de configuración con APIYI:

{\n  "llm": {\n    "provider": "openai-compatible",\n    "endpoint": "https://api.apiyi.com/v1",\n    "apiKey": "tu-api-key-de-apiyi",\n    "model": "claude-3-5-sonnet-20241022"\n  }\n}

APIYI acepta pagos locales y tiene descuentos.

Mantener Activo 24/7

Opción 1: Pantalla en Segundo Plano (Mac/Linux)

# Iniciar\nscreen -S openclaw\nopenclaw gateway\n# Ctrl+A, D para desconectar\n\n# Reconectar\nscreen -r openclaw

Opción 2: Servicio del Sistema

openclaw service install\nopenclaw service start

Esto crea un servicio que inicia automáticamente.

Opción 3: VPS

Para disponibilidad real 24/7, usá un VPS barato ($5/mes en DigitalOcean o similar).

Solución de Problemas

WhatsApp se Desconecta

WhatsApp Web puede desconectarse. Solución:

openclaw channels reconnect whatsapp

Si persiste, volvé a escanear el QR.

Telegram No Responde

Verificá que el token sea correcto:

openclaw doctor

Errores de API

Si ves errores 429 (rate limit), mirá nuestra guía de errores comunes en APIs de IA.

Tips de Uso

1. Contexto Persistente

OpenClaw recuerda conversaciones. Podés decir:

Recordá que me llamo Juan y trabajo en fintech.

Y lo recordará en futuras conversaciones.

2. Comandos Útiles

  • /clear - Limpiar contexto
  • /model - Cambiar modelo
  • /tokens - Ver uso de tokens

3. Multimedia

Podés enviar imágenes y OpenClaw las analizará (con modelos que soporten visión).

Conclusión

Con WhatsApp y Telegram configurados, tenés a Claude disponible donde sea. Es especialmente útil para:

  • Consultas rápidas cuando no estás en la PC
  • Compartir el asistente con familia/equipo
  • Automatizaciones y recordatorios

El setup inicial lleva unos minutos, pero después es magia pura. Si querés ir más allá, aprendé sobre automatización con Skills.
