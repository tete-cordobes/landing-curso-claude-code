Automatizar con Claude Code + N8N: Guía Práctica

Aprende a combinar Claude Code con N8N para crear flujos de trabajo automatizados con IA. Tutorial paso a paso con ejemplos prácticos.

¿Por Qué Combinar Claude Code y N8N?

Claude Code es excelente para desarrollo y tareas de código. N8N es una plataforma de automatización visual que conecta aplicaciones y servicios.

Juntos, pueden automatizar flujos de trabajo complejos que incluyan generación de código, procesamiento de datos y respuestas inteligentes. Si quieres dominar Claude Code, el curso de Claude Code te enseña todo lo necesario.

¿Qué es N8N?

N8N es una herramienta de automatización de código abierto similar a Zapier pero más potente y personalizable.

  • Visual: Crea flujos arrastrando nodos
  • Self-hosted: Puedes correrlo en tu servidor
  • Extensible: Crea nodos personalizados
  • Gratis: Self-hosted es gratuito

Casos de Uso

1. Generador de Contenido Automático

Trigger: Nuevo artículo en RSS → Claude genera resumen → Publica en redes.

2. Asistente de Código Automatizado

Trigger: Issue en GitHub → Claude analiza y sugiere fix → Crea PR.

3. Procesador de Emails

Trigger: Email recibido → Claude clasifica y responde → Log en Notion.

4. Data Pipeline Inteligente

Trigger: Datos nuevos → Claude procesa y enriquece → Guarda en DB.

Configuración de N8N

Instalación Local

# Con Docker
docker run -it --rm \\
  --name n8n \\
  -p 5678:5678 \\
  -v ~/.n8n:/home/node/.n8n \\
  n8nio/n8n

Instalación con npm

npm install n8n -g
n8n start

Accede a http://localhost:5678

Conectar Claude API a N8N

Primero necesitas tu API key de Claude. Si aún no la tienes, revisa nuestro tutorial de Claude API.

Paso 1: Crear Credenciales

  1. Ve a Settings > Credentials
  2. Click "Add Credential"
  3. Busca "HTTP Request" (para APIs custom)
  4. Añade tu API key de Anthropic

Paso 2: Nodo HTTP Request

{
  "method": "POST",
  "url": "https://api.anthropic.com/v1/messages",
  "headers": {
    "x-api-key": "{{$credentials.anthropicApiKey}}",
    "anthropic-version": "2023-06-01",
    "content-type": "application/json"
  },
  "body": {
    "model": "claude-3-5-sonnet-20241022",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "{{$json.prompt}}"}
    ]
  }
}

Integrar Claude Code Directamente

Puedes ejecutar Claude Code desde N8N usando el nodo "Execute Command". Conoce los comandos esenciales de Claude Code para sacarle el máximo provecho.

cd /ruta/al/proyecto && echo "Tu prompt aquí" | claude --no-interactive

Esto permite que N8N trigger Claude Code para modificar código automáticamente.

Mejores Prácticas

  1. Limita tokens: Usa max_tokens para controlar costos. Consulta los precios de APIs de IA para optimizar gastos.
  2. Cachea respuestas: Guarda en Redis para prompts repetidos
  3. Maneja errores: Añade nodos de error handling. Ver errores comunes en APIs de IA.
  4. Logs: Registra todas las llamadas para debugging
  5. Rate limiting: Respeta los límites de la API

Nodo Personalizado para Claude

Para uso frecuente, considera crear un nodo N8N personalizado:

// claude-node.ts
import { IExecuteFunctions } from 'n8n-core';

export class Claude {
  async execute(this: IExecuteFunctions) {
    const prompt = this.getNodeParameter('prompt', 0) as string;
    // Lógica de llamada a Claude API
  }
}

Costos y Optimización

  • Usa Haiku: Para tareas simples, 90% más barato
  • Batch requests: Agrupa múltiples prompts
  • Filtra: No proceses todo, usa condiciones
