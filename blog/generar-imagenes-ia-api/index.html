DALL-E 3 (OpenAI)

Instalación

pip install openai

Generar Imagen

from openai import OpenAI

client = OpenAI()

response = client.images.generate(
    model="dall-e-3",
    prompt="Un gato astronauta flotando en el espacio, \
            estilo ilustración digital, colores vibrantes",
    size="1024x1024",
    quality="hd",
    n=1
)

image_url = response.data[0].url
print(image_url)

Parámetros

  • size: 1024x1024, 1024x1792, 1792x1024
  • quality: standard, hd
  • style: vivid, natural

Stable Diffusion API

Via Stability AI

import requests

response = requests.post(
    "https://api.stability.ai/v1/generation/stable-diffusion-xl-1024-v1-0/text-to-image",
    headers={
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json",
    },
    json={
        "text_prompts": [{"text": "Un paisaje futurista"}],
        "cfg_scale": 7,
        "height": 1024,
        "width": 1024,
        "samples": 1,
        "steps": 30,
    },
)

data = response.json()
image_base64 = data["artifacts"][0]["base64"]

Flux API

Flux es el nuevo estándar en calidad de imagen:

import replicate

output = replicate.run(
    "black-forest-labs/flux-schnell",
    input={
        "prompt": "Retrato fotorealista de una mujer, \
                   iluminación de estudio, 8K",
        "num_outputs": 1,
        "aspect_ratio": "1:1",
        "output_format": "webp"
    }
)

print(output[0])

Escribir Buenos Prompts

Estructura Efectiva

[SUJETO] + [DETALLES] + [ESTILO] + [ILUMINACIÓN] + [CALIDAD]

Ejemplo

"Una taza de café humeante sobre una mesa de madera rústica,
con un libro abierto al lado, luz natural de ventana,
estilo fotografía de producto, 4K, bokeh suave"

Palabras Clave Útiles

  • Calidad: 4K, 8K, ultra detailed, high resolution
  • Estilo: photorealistic, watercolor, digital art, anime
  • Iluminación: golden hour, studio lighting, dramatic
  • Cámara: 50mm lens, wide angle, macro shot

Image-to-Image

Transformar imágenes existentes:

# DALL-E 3 edición
response = client.images.edit(
    model="dall-e-2",  # Solo DALL-E 2 soporta edit
    image=open("imagen.png", "rb"),
    mask=open("mascara.png", "rb"),
    prompt="Añade un sombrero rojo",
    n=1,
    size="1024x1024"
)

Variaciones de Imagen

response = client.images.create_variation(
    image=open("imagen.png", "rb"),
    n=4,
    size="1024x1024"
)

  3. Cachea resultados frecuentes

Consideraciones Legales

  • Verifica los términos de uso de cada API
  • Algunas prohíben generar rostros de personas reales
  • El copyright de imágenes generadas varía por servicio
  • Marca las imágenes como generadas por IA si es requerido

Conclusión

La generación de imágenes por API está madura y accesible. Elige según tu balance de calidad vs costo:

  • Máxima calidad: DALL-E 3 o Flux
  • Máximo volumen: Stable Diffusion
  • Mejor texto en imágenes: Ideogram
