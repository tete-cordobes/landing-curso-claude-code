10 Comandos de Claude Code que Debes Conocer

Domina los comandos más útiles de Claude Code. Desde slash commands hasta atajos de teclado, aprende a ser más productivo con esta guía completa.

Los Comandos Esenciales de Claude Code

Claude Code tiene comandos poderosos que multiplican tu productividad. En esta guía te muestro los 10 comandos que debes conocer para sacarle el máximo provecho.

Si todavía no tenés Claude Code instalado, empezá por nuestra guía qué es Claude Code y cómo empezar.

Slash Commands Básicos

1. /help - Tu Guía de Referencia

/help

Muestra todos los comandos disponibles con descripciones. Úsalo cuando no recuerdes un comando.

2. /clear - Empezar de Cero

/clear

Limpia el historial de la conversación actual. Útil cuando quieres empezar un tema nuevo sin contexto anterior.

3. /compact - Modo Eficiente

/compact

Activa el modo compacto que usa menos tokens. Ideal para tareas simples donde no necesitas todo el contexto del proyecto. Esto ayuda a optimizar costos de API.

4. /init - Configurar Proyecto

/init

Inicializa la configuración de Claude Code en tu proyecto. Crea un archivo .claude con preferencias.

Comandos de Archivos

5. @archivo - Referencia Directa

Revisa @src/utils/auth.js y mejora el manejo de errores

Usa @ seguido de la ruta para referenciar archivos específicos. Claude los leerá automáticamente.

6. /add - Añadir al Contexto

/add src/components/

Añade archivos o carpetas al contexto de la conversación. Útil para que Claude entienda más de tu proyecto.

7. /diff - Ver Cambios

/diff

Muestra los cambios que Claude ha propuesto antes de aplicarlos. Te da control sobre qué se modifica.

Comandos Avanzados

8. /run - Ejecutar Comandos

/run npm test

Ejecuta comandos del sistema directamente. Claude puede ver el output y ayudarte a resolver problemas. Muy útil para testing automatizado.

9. /undo - Deshacer Cambios

/undo

Revierte el último cambio que hizo Claude. Tranquilidad de que siempre puedes volver atrás.

10. /commit - Git Integrado

/commit

Crea un commit con los cambios actuales. Claude genera automáticamente un mensaje descriptivo.

Atajos de Teclado

Ctrl+CCancelar operación actual
Ctrl+DSalir de Claude Code

Combinaciones Poderosas

Debug Completo

/run npm test\nEl test está fallando, analiza el error y corrígelo

Refactor con Contexto

/add src/services/\nRefactoriza todos los servicios para usar async/await

Documentación Automática

@src/utils/\nGenera documentación JSDoc para todas las funciones

Configuración Personalizada

Crea un archivo .claude/config.json en tu proyecto:

{\n  "model": "claude-3-opus",\n  "autoApprove": false,\n  "maxTokens": 4096,\n  "excludePatterns": ["node_modules", ".git", "dist"]\n}

Integración con VS Code

Estos comandos funcionan mejor cuando tenés Claude Code integrado con VS Code. Podés tener la terminal de Claude Code abierta mientras editás visualmente.

Tips de Productividad

  1. Usa referencias específicas: @archivo.js:línea para ser preciso
  2. Combina comandos: Primero /add, luego tu petición
  3. Revisa con /diff: Siempre antes de aceptar cambios grandes
  4. Aprovecha /compact: Para tareas simples ahorra tokens
