Cherry Studio + APIs de IA: Guía de Configuración

Configura Cherry Studio para usar múltiples APIs de IA. Tutorial paso a paso para conectar OpenAI, Claude, Gemini y más.

¿Qué es Cherry Studio?

Cherry Studio es una aplicación de escritorio gratuita que te permite usar múltiples APIs de IA desde una interfaz unificada. Es como tener ChatGPT, Claude y Gemini en una sola app.

Si quieres aprender a usar estas APIs de forma profesional, el curso de Claude Code te enseña a dominarlas.

Características Principales

  • Soporta múltiples proveedores de API
  • Interfaz limpia y moderna
  • Historial de conversaciones
  • Exportación de chats
  • Temas personalizables
  • Gratis y open source

Instalación

Windows

  1. Ve a cherry-ai.com
  2. Descarga el instalador .exe
  3. Ejecuta e instala

macOS

  1. Descarga el .dmg
  2. Arrastra a Aplicaciones
  3. Abre desde Launchpad

Linux

# AppImage
chmod +x CherryStudio.AppImage
./CherryStudio.AppImage

Configurar OpenAI

  1. Abre Cherry Studio
  2. Ve a Settings > API Providers
  3. Click en OpenAI
  4. Ingresa tu API key
  5. Selecciona modelos disponibles
  6. Click Save

Configuración Recomendada

API Endpoint: https://api.openai.com/v1
API Key: sk-...
Models: gpt-4-turbo, gpt-4o, gpt-4o-mini

Configurar Claude (Anthropic)

Para obtener tu API key de Claude, sigue nuestro tutorial de Claude API.

  1. Ve a Settings > API Providers
  2. Click en Anthropic
  3. Ingresa tu API key
  4. Guarda configuración

Configuración

API Endpoint: https://api.anthropic.com
API Key: sk-ant-...
Models: claude-3-5-sonnet-20241022, claude-3-haiku

Configurar Gemini

  1. Ve a Settings > API Providers
  2. Click en Google
  3. Ingresa tu API key de Google AI Studio

Configuración

API Key: AIza...
Models: gemini-1.5-pro, gemini-1.5-flash

Configurar API Router (APIYI/OpenRouter)

Para usar múltiples modelos desde un solo endpoint:

  1. Ve a Settings > Custom Provider
  2. Añade nuevo proveedor
  3. Configura:
Name: APIYI
API Endpoint: https://api.apiyi.com/v1
API Key: tu-key-de-apiyi
Models: gpt-4o, claude-3-5-sonnet, gemini-1.5-pro

Solución de Problemas

Si encuentras errores, consulta nuestra guía de errores comunes en APIs de IA.

Error 403: Forbidden

  • Verifica que la API key sea correcta
  • Confirma que tienes créditos disponibles
  • Revisa que el endpoint sea correcto

Error de Conexión

  • Verifica tu conexión a internet
  • Prueba con VPN si estás en región restringida
  • Revisa firewall/antivirus

Modelos no Aparecen

  • Refresca la lista de modelos
  • Verifica que tu cuenta tenga acceso al modelo
  • Algunos modelos requieren tier específico

Tips de Uso

1. Crear Perfiles

Crea perfiles diferentes para cada tipo de tarea:

  • Código: Claude Sonnet con temperature 0.3
  • Creativo: GPT-4o con temperature 0.8
  • Rápido: Haiku/Flash para consultas simples

2. Atajos de Teclado

  • Cmd/Ctrl + N: Nueva conversación
  • Cmd/Ctrl + Enter: Enviar mensaje
  • Cmd/Ctrl + K: Cambiar modelo

3. Exportar Conversaciones

Ve a la conversación > Click derecho > Export como Markdown o JSON.

Conclusión

Cherry Studio es excelente para quienes usan múltiples APIs de IA. La configuración es sencilla y la interfaz intuitiva.

Combínalo con un API router como APIYI para máxima flexibilidad y ahorro en costos. Para conocer los precios actualizados, consulta nuestra guía de precios de APIs de IA. Y si prefieres una herramienta de terminal más potente, prueba Claude Code con el curso de Claude Code.
