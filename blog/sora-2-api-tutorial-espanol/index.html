Sora 2 API: Tutorial Completo en Español 2026

Aprende a usar la API de Sora 2 de OpenAI para generar videos con IA. Tutorial con ejemplos de código, parámetros y solución de errores.

¿Qué es Sora 2?

Sora 2 es el modelo de generación de video de OpenAI. Puede crear videos realistas de hasta 1 minuto a partir de descripciones de texto.

En este tutorial aprenderás a usar la Sora 2 API para integrar generación de video en tus aplicaciones. Si buscas más opciones gratuitas, revisa nuestra guía completa para crear videos con IA gratis en 2026.

Capacidades de Sora 2

  • Text-to-Video: Describe lo que quieres y genera el video
  • Image-to-Video: Anima una imagen estática
  • Video-to-Video: Transforma videos existentes
  • Duración: 5 segundos a 1 minuto
  • Resolución: Hasta 1080p

Acceso a Sora 2 API

Opción 1: Directamente de OpenAI

Necesitas una cuenta de OpenAI con acceso a la API y créditos suficientes. Consulta nuestra guía de precios de APIs de IA para estimar costos.

Opción 2: API Routers (Más Económico)

Servicios como APIYI ofrecen acceso a Sora 2 con descuentos de hasta 20%.

Configuración Inicial

Instalar SDK

# Python
pip install openai

# JavaScript
npm install openai

Configurar API Key

export OPENAI_API_KEY="tu-api-key"

Tu Primera Generación de Video

Python

from openai import OpenAI

client = OpenAI()

response = client.videos.create(
    model="sora-2",
    prompt="Un gato naranja caminando por un jardín japonés \
            con cerezos en flor, cinematográfico, 4K",
    duration=10,  # segundos
    resolution="1080p",
    aspect_ratio="16:9"
)

print(f"Video URL: {response.video_url}")

JavaScript

import OpenAI from 'openai';

const openai = new OpenAI();

const response = await openai.videos.create({
    model: 'sora-2',
    prompt: 'Un gato naranja caminando por un jardín japonés',
    duration: 10,
    resolution: '1080p',
    aspect_ratio: '16:9'
});

console.log(`Video URL: ${response.video_url}`);

Parámetros de la API

ParámetroTipoDescripción
promptstringDescripción del video (obligatorio)
durationintegerDuración en segundos (5-60)
resolutionstring720p, 1080p
aspect_ratiostring16:9, 9:16, 1:1
stylestringcinematic, animated, realistic

Escribir Buenos Prompts

Estructura Recomendada

[SUJETO] + [ACCIÓN] + [ESCENARIO] + [ESTILO] + [CÁMARA]

Ejemplos de Prompts Efectivos

Bueno:

"Una mujer con vestido rojo caminando por las calles de París
al atardecer, estilo cinematográfico, cámara siguiendo
al personaje, iluminación dorada, 24fps"

Malo:

"Video bonito de París"

Aspect Ratios por Plataforma

  • 16:9: YouTube, TV, presentaciones
  • 9:16: TikTok, Instagram Stories, YouTube Shorts
  • 1:1: Instagram Feed, Twitter

Errores Comunes y Soluciones

Estos errores son similares a los que encontrarás en otras APIs. Consulta nuestra guía completa de errores comunes en APIs de IA para más detalles.

moderation_blocked

El contenido viola las políticas de uso.

Solución: Revisa que tu prompt no incluya contenido prohibido (violencia, contenido adulto, etc.).

invalid_value duration

La duración solicitada no es válida.

Solución: Usa valores entre 5 y 60 segundos.

rate_limit_exceeded

Has excedido el límite de peticiones.

Solución: Espera unos minutos o aumenta tu tier de uso.

insufficient_quota

No tienes créditos suficientes.

Solución: Añade créditos a tu cuenta o usa un API router más económico.

Ejemplo Avanzado: Generar Múltiples Videos

prompts = [
    "Amanecer en las montañas, timelapse, 4K",
    "Olas rompiendo en la playa, cámara lenta",
    "Ciudad futurista de noche, estilo cyberpunk"
]

for prompt in prompts:
    response = client.videos.create(
        model="sora-2",
        prompt=prompt,
        duration=5,
        resolution="1080p"
    )
    print(f"Generado: {response.video_url}")
