Gemini API: Guía Completa en Español 2026

Tutorial completo de la API de Gemini de Google. Aprende a usar Gemini 2.5 Pro con ejemplos de código y mejores prácticas.

¿Qué es Gemini API?

Gemini es la familia de modelos de IA de Google. La API de Gemini te permite integrar estos modelos en tus aplicaciones.

El punto fuerte de Gemini: 1 millón de tokens de contexto en Gemini 1.5 Pro. Si quieres aprender a usar múltiples APIs de IA, el curso de Claude Code te enseña a integrarlas profesionalmente.

Obtener API Key

  1. Ve a aistudio.google.com
  2. Inicia sesión con tu cuenta de Google
  3. Click en "Get API key"
  4. Crea una nueva key o usa existente

Instalación

Python

pip install google-generativeai

JavaScript

npm install @google/generative-ai

Primera Llamada a la API

Python

import google.generativeai as genai

genai.configure(api_key="tu-api-key")

model = genai.GenerativeModel('gemini-1.5-pro')
response = model.generate_content("Explica qué es Python en 3 frases")

print(response.text)

JavaScript

import { GoogleGenerativeAI } from '@google/generative-ai';

const genAI = new GoogleGenerativeAI('tu-api-key');
const model = genAI.getGenerativeModel({ model: 'gemini-1.5-pro' });

const result = await model.generateContent('Explica qué es Python');
console.log(result.response.text());

El Superpoder: 1 Millón de Tokens

Gemini puede procesar documentos enormes de una sola vez:

# Leer un libro completo
with open('libro_completo.txt', 'r') as f:
    libro = f.read()

response = model.generate_content(f"""
Analiza este libro y dame:
1. Resumen ejecutivo
2. Personajes principales
3. Temas centrales
4. Citas memorables

Libro:
{libro}
""")

Multimodalidad: Texto + Imágenes

Gemini puede analizar imágenes:

import PIL.Image

img = PIL.Image.open('imagen.jpg')

response = model.generate_content([
    "Describe esta imagen en detalle",
    img
])

print(response.text)

Chat Conversacional

chat = model.start_chat(history=[])

response = chat.send_message("Hola, ¿qué puedes hacer?")
print(response.text)

response = chat.send_message("Dame un ejemplo de código Python")
print(response.text)

Configuración Avanzada

generation_config = {
    "temperature": 0.7,
    "top_p": 0.9,
    "top_k": 40,
    "max_output_tokens": 2048,
}

model = genai.GenerativeModel(
    model_name='gemini-1.5-pro',
    generation_config=generation_config
)

Safety Settings

Controla el filtrado de contenido:

safety_settings = [
    {"category": "HARM_CATEGORY_HARASSMENT", "threshold": "BLOCK_MEDIUM_AND_ABOVE"},
    {"category": "HARM_CATEGORY_HATE_SPEECH", "threshold": "BLOCK_MEDIUM_AND_ABOVE"},
]

model = genai.GenerativeModel(
    'gemini-1.5-pro',
    safety_settings=safety_settings
)

Streaming

response = model.generate_content(
    "Escribe un cuento largo",
    stream=True
)

for chunk in response:
    print(chunk.text, end="")

Cuándo Usar Gemini

  • Documentos largos: PDFs, libros, transcripciones
  • Análisis de código: Repositorios completos
  • Multimodal: Cuando necesitas texto + imagen
  • Costo efectivo: Flash es muy económico

Errores Comunes

Si encuentras problemas, consulta nuestra guía de errores comunes en APIs de IA.

SAFETY_BLOCK

El contenido fue bloqueado por filtros de seguridad. Ajusta safety_settings o reformula.

QUOTA_EXCEEDED

Has excedido tu cuota gratuita. Añade billing o espera el reset.

Conclusión

Gemini API es excelente para tareas que requieren mucho contexto. El millón de tokens es un diferenciador único.
