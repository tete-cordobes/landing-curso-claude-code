Cómo Usar OpenClaw con APIYI: Guía de Configuración

Configura OpenClaw para usar APIYI como proxy de API. Ideal si no tenés tarjeta internacional o querés ahorrar en costos.

¿Por Qué Usar APIYI con OpenClaw?

APIYI es un API router que te permite acceder a modelos como Claude y GPT-4 sin necesitar tarjeta de crédito internacional. Ventajas:

  • Pagos locales: Alipay, WeChat, transferencia
  • Sin tarjeta internacional: Ideal para LATAM
  • Descuentos: A veces más barato que directo
  • Multi-modelo: Un endpoint, todos los modelos

Si estás haciendo el curso de Claude Code y no tenés acceso fácil a la API directa, APIYI es tu mejor opción.

Crear Cuenta en APIYI

  1. Ve a apiyi.com
  2. Registrate con email
  3. Verificá tu cuenta
  4. Cargá créditos con tu método preferido
  5. Generá una API key en el dashboard

Configurar OpenClaw

Si todavía no tenés OpenClaw instalado, empezá por nuestra guía completa de OpenClaw.

Método 1: Comando de Configuración

openclaw configure --section llm

Cuando te pregunte:

  • Provider: openai-compatible
  • Endpoint: https://api.apiyi.com/v1
  • API Key: tu-api-key-de-apiyi
  • Model: claude-3-5-sonnet-20241022

Método 2: Editar Configuración Directamente

Editá ~/.openclaw/openclaw.json:

{\n  "llm": {\n    "provider": "openai-compatible",\n    "endpoint": "https://api.apiyi.com/v1",\n    "apiKey": "sk-apiyi-xxxxxxxxxxxxx",\n    "model": "claude-3-5-sonnet-20241022",\n    "maxTokens": 4096,\n    "temperature": 0.7\n  }\n}

Modelos Disponibles en APIYI

APIYI soporta múltiples modelos. Los más usados con OpenClaw:

Claude (Anthropic)

  • claude-3-5-sonnet-20241022 - Mejor balance calidad/costo
  • claude-3-opus-20240229 - Máxima calidad
  • claude-3-haiku-20240307 - Más rápido y barato

Para entender las diferencias, mirá nuestro tutorial de Claude API.

GPT (OpenAI)

  • gpt-4o - Último modelo multimodal
  • gpt-4-turbo - Buena calidad, buen precio
  • gpt-4o-mini - Económico

Otros

  • gemini-1.5-pro - Google
  • deepseek-chat - DeepSeek

Tenemos guías de todos estos en nuestra guía de APIs de IA.

Configuración Multi-Modelo

Podés configurar diferentes modelos para diferentes usos:

{\n  "llm": {\n    "provider": "openai-compatible",\n    "endpoint": "https://api.apiyi.com/v1",\n    "apiKey": "sk-apiyi-xxxxxxxxxxxxx",\n    "models": {\n      "default": "claude-3-5-sonnet-20241022",\n      "fast": "claude-3-haiku-20240307",\n      "smart": "claude-3-opus-20240229",\n      "cheap": "gpt-4o-mini"\n    }\n  }\n}

Después podés cambiar con /model fast en el chat.

Verificar Conexión

openclaw doctor

Deberías ver:

✓ LLM endpoint reachable\n✓ API key valid\n✓ Model available

Probar

openclaw chat

Escribí algo y verificá que responda.

Optimizar Costos

1. Usar Haiku para Consultas Simples

No necesitás Sonnet para preguntas básicas:

{\n  "routing": {\n    "simple_queries": {\n      "pattern": "(clima|hora|fecha|qué es)",\n      "model": "claude-3-haiku-20240307"\n    },\n    "default": "claude-3-5-sonnet-20241022"\n  }\n}

2. Limitar Contexto

Menos tokens de contexto = menos costo:

{\n  "llm": {\n    "contextMessages": 10,\n    "maxContextTokens": 8000\n  }\n}

3. Cache de Respuestas

Para preguntas repetitivas:

{\n  "cache": {\n    "enabled": true,\n    "ttl": 3600\n  }\n}

Para más tips de optimización, mirá nuestra guía de precios de APIs.

Solución de Problemas

Error 401: Unauthorized

  • Verificá que la API key sea correcta
  • Asegurate de tener créditos en APIYI

Error 429: Rate Limited

  • Esperá un minuto
  • Considerá upgrade de tier en APIYI

Más errores comunes en nuestra guía de troubleshooting.

Error de Modelo No Encontrado

  • Verificá el nombre exacto del modelo
  • Algunos modelos requieren acceso especial

Respuestas Lentas

  • APIYI agrega latencia mínima (~50-100ms)
  • Para latencia crítica, usá API directa

Conclusión

APIYI es la forma más fácil de usar OpenClaw si estás en LATAM o no tenés tarjeta internacional. La configuración toma 5 minutos y funciona igual que la API directa.

Combiná APIYI con routing inteligente de modelos para optimizar costos sin sacrificar calidad. Y si querés dominar todas estas herramientas, el curso de Claude Code te da las bases para convertirte en un power user de IA.
