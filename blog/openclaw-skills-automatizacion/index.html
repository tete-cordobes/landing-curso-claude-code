OpenClaw Skills: Automatiza tu Vida con IA

Aprende a usar y crear skills en OpenClaw. Desde búsqueda web hasta domótica con Home Assistant.

¿Qué son los Skills de OpenClaw?

Los Skills son habilidades que extienden lo que OpenClaw puede hacer. Van desde búsqueda web hasta controlar tu casa inteligente.

Pensalo así: Claude es el cerebro, los skills son las manos. Si venís siguiendo el curso de Claude Code, ya sabés que Claude es poderoso, pero con skills se vuelve MUCHO más útil.

Skills Incluidos por Defecto

1. Web Search

Busca información actualizada en internet:

Usuario: ¿Cuál es el clima en Buenos Aires hoy?\nOpenClaw: [Busca en web] Hoy en Buenos Aires: 28°C, parcialmente nublado...

2. File Operations

Lee y escribe archivos en tu sistema:

Usuario: Leé el archivo ~/notas/ideas.md\nOpenClaw: El contenido del archivo es...

3. Browser Control

Controla el navegador para tareas automatizadas:

Usuario: Abrí YouTube y buscá tutoriales de Python\nOpenClaw: [Abre navegador, navega a YouTube, busca...]

4. Code Execution

Ejecuta código en un sandbox seguro:

Usuario: Ejecutá este Python: print(2**10)\nOpenClaw: Resultado: 1024

Instalar Skills de la Comunidad

Hay más de 100 skills creados por la comunidad:

# Ver skills disponibles\nopenclaw skills search\n\n# Instalar un skill\nopenclaw skills install weather\nopenclaw skills install home-assistant\nopenclaw skills install spotify

Skills Populares

  • weather: Clima detallado por ubicación
  • home-assistant: Control de domótica
  • spotify: Control de reproducción
  • calendar: Integración con Google Calendar
  • todoist: Gestión de tareas
  • notion: Notas y bases de datos
  • github: Gestión de repos

Crear tu Propio Skill

Skill Básico (Markdown)

Creá un archivo en ~/.openclaw/skills/:

# ~/.openclaw/skills/saludo.md\n\n# Skill: Saludo Personalizado\n\n## Descripción\nResponde saludos de forma personalizada.\n\n## Triggers\n- hola\n- buenos días\n- buenas tardes\n\n## Respuesta\nCuando el usuario salude, respondé de forma amigable\nmencionando la hora del día y deseándole algo positivo.

Skill Avanzado (TypeScript)

Para skills con lógica compleja:

// ~/.openclaw/skills/crypto-price.ts\n\nimport { Skill, Context } from '@openclaw/sdk';\n\nexport default class CryptoPrice implements Skill {\n  name = 'crypto-price';\n  description = 'Obtiene precios de criptomonedas';\n  \n  triggers = ['precio de', 'cuánto vale', 'cotización'];\n  \n  async execute(ctx: Context) {\n    const crypto = ctx.extractEntity('cryptocurrency');\n    const response = await fetch(\n      `https://api.coingecko.com/api/v3/simple/price?ids=${crypto}&vs_currencies=usd`\n    );\n    const data = await response.json();\n    return `${crypto}: $${data[crypto].usd} USD`;\n  }\n}

Si querés aprender TypeScript para crear skills más potentes, el curso de Claude Code te enseña a programar con IA de manera efectiva.

Automatización con Cron

OpenClaw puede ejecutar tareas programadas, similar a lo que hacemos con N8N y Claude Code:

Configurar Tareas Programadas

En ~/.openclaw/openclaw.json:

{\n  "cron": {\n    "morning_briefing": {\n      "schedule": "0 8 * * *",\n      "channel": "telegram",\n      "action": "Dame un resumen del clima, mis eventos de hoy y las noticias tech más importantes"\n    },\n    "weekly_review": {\n      "schedule": "0 18 * * 5",\n      "channel": "whatsapp",\n      "action": "Hacé un resumen de lo que hice esta semana basándote en mis mensajes"\n    }\n  }\n}

Sintaxis de Cron

┌───────────── minuto (0-59)\n│ ┌─────────── hora (0-23)\n│ │ ┌───────── día del mes (1-31)\n│ │ │ ┌─────── mes (1-12)\n│ │ │ │ ┌───── día de la semana (0-6)\n│ │ │ │ │\n* * * * *

Ejemplos:

  • 0 9 * * * - Todos los días a las 9:00
  • 0 9 * * 1-5 - Lunes a viernes a las 9:00
  • */30 * * * * - Cada 30 minutos

Integración con Home Assistant

Controlá tu casa inteligente:

1. Instalar el Skill

openclaw skills install home-assistant

2. Configurar

{\n  "skills": {\n    "home-assistant": {\n      "url": "http://homeassistant.local:8123",\n      "token": "tu-long-lived-access-token"\n    }\n  }\n}

3. Usar

Usuario: Apagá las luces del living\nOpenClaw: [Ejecuta Home Assistant] Luces del living apagadas.\n\nUsuario: ¿Está abierta la puerta del garage?\nOpenClaw: [Consulta sensor] La puerta del garage está cerrada.

Multi-Agente

OpenClaw soporta múltiples agentes especializados:

{\n  "agents": {\n    "coder": {\n      "model": "claude-3-5-sonnet",\n      "systemPrompt": "Sos un experto en programación...",\n      "skills": ["code-execution", "github"]\n    },\n    "assistant": {\n      "model": "claude-3-haiku",\n      "systemPrompt": "Sos un asistente amigable...",\n      "skills": ["calendar", "weather", "web-search"]\n    }\n  },\n  "routing": {\n    "keywords": {\n      "código|programar|debug": "coder",\n      "default": "assistant"\n    }\n  }\n}

Para entender mejor cómo funcionan los modelos, mirá nuestra comparativa OpenAI vs Claude API.

Webhooks

Recibí eventos externos y reaccioná:

{\n  "webhooks": {\n    "github_pr": {\n      "path": "/webhook/github",\n      "action": "Avisame que hay un nuevo PR: {{payload.pull_request.title}}"\n    }\n  }\n}

Tips de Automatización

1. Empezá Simple

No intentes automatizar todo de una. Empezá con UNA tarea que te ahorre tiempo real.

2. Probá Antes de Programar

Antes de poner algo en cron, probalo manualmente varias veces.

3. Logs son tu Amigo

openclaw logs -f

Mirá los logs cuando algo no funciona.

4. Límites de Seguridad

Siempre poné límites en skills que interactúan con el mundo real:

{\n  "skills": {\n    "home-assistant": {\n      "allowedDomains": ["light", "switch"],\n      "deniedEntities": ["lock.*", "alarm.*"]\n    }\n  }\n}

Conclusión

Los skills transforman a OpenClaw de un chatbot a un verdadero asistente personal. La clave es automatizar tareas que hacés repetidamente.

Empezá con los skills incluidos, explorá los de la comunidad, y eventualmente creá los tuyos propios. Si querés aprender a crear automatizaciones más complejas, el curso de Claude Code te da las bases para dominar la IA como herramienta.
