Claude API Tutorial: Guía Completa en Español 2026

Aprende a usar la API de Claude de Anthropic. Tutorial con ejemplos de código en Python y JavaScript para integrar Claude en tus aplicaciones.

¿Qué es la API de Claude?

La API de Claude te permite integrar el modelo de inteligencia artificial de Anthropic en tus propias aplicaciones. Puedes crear chatbots, asistentes, generadores de contenido y mucho más.

Si querés usar Claude para programar, mirá también qué es Claude Code, la CLI oficial. Y para dominar todo, el curso de Claude Code.

Ventajas de Claude API

  • Contexto extenso: Hasta 200K tokens de contexto
  • Razonamiento avanzado: Excelente para tareas complejas
  • Código de calidad: Genera código limpio y funcional
  • Multilenguaje: Funciona muy bien en español
  • Seguro: Diseñado para ser útil y seguro

Comparamos Claude con otras APIs en OpenAI vs Claude API.

Requisitos

  • Cuenta en Anthropic (console.anthropic.com)
  • API Key
  • Python 3.8+ o Node.js 18+

Obtener tu API Key

  1. Registra en console.anthropic.com
  2. Añade método de pago (se cobra por uso)
  3. Ve a "API Keys" > "Create Key"
  4. Guarda la key de forma segura

Instalación

Python

pip install anthropic

JavaScript/Node.js

npm install @anthropic-ai/sdk

Tu Primera Llamada a la API

Python

import anthropic\n\nclient = anthropic.Anthropic(\n    api_key="tu-api-key"\n)\n\nmessage = client.messages.create(\n    model="claude-3-5-sonnet-20241022",\n    max_tokens=1024,\n    messages=[\n        {"role": "user", "content": "Hola, ¿cómo estás?"}\n    ]\n)\n\nprint(message.content[0].text)

JavaScript

import Anthropic from '@anthropic-ai/sdk';\n\nconst anthropic = new Anthropic({\n    apiKey: 'tu-api-key'\n});\n\nconst message = await anthropic.messages.create({\n    model: 'claude-3-5-sonnet-20241022',\n    max_tokens: 1024,\n    messages: [\n        { role: 'user', content: 'Hola, ¿cómo estás?' }\n    ]\n});\n\nconsole.log(message.content[0].text);

Parámetros Importantes

max_tokens

Máximo de tokens en la respuesta. Más tokens = respuestas más largas.

temperature

Controla la creatividad (0-1). Bajo = más predecible, alto = más creativo.

message = client.messages.create(\n    model="claude-3-5-sonnet-20241022",\n    max_tokens=2048,\n    temperature=0.7,  # Creatividad media\n    messages=[...]\n)

system

Instrucciones de comportamiento para Claude.

message = client.messages.create(\n    model="claude-3-5-sonnet-20241022",\n    max_tokens=1024,\n    system="Eres un asistente experto en Python. Responde siempre con ejemplos de código.",\n    messages=[...]\n)

Conversaciones Multi-turno

messages = [\n    {"role": "user", "content": "¿Qué es Python?"},\n    {"role": "assistant", "content": "Python es un lenguaje..."},\n    {"role": "user", "content": "¿Cómo instalo una librería?"}\n]\n\nresponse = client.messages.create(\n    model="claude-3-5-sonnet-20241022",\n    max_tokens=1024,\n    messages=messages\n)

Streaming de Respuestas

Para respuestas largas, usa streaming:

with client.messages.stream(\n    model="claude-3-5-sonnet-20241022",\n    max_tokens=1024,\n    messages=[{"role": "user", "content": "Escribe un cuento"}]\n) as stream:\n    for text in stream.text_stream:\n        print(text, end="", flush=True)

Manejo de Errores

Tenemos una guía completa de errores de APIs. Los más comunes:

import anthropic\n\ntry:\n    response = client.messages.create(...)\nexcept anthropic.RateLimitError:\n    print("Límite de peticiones alcanzado")\nexcept anthropic.AuthenticationError:\n    print("API key inválida")\nexcept anthropic.APIError as e:\n    print(f"Error de API: {e}")

Ejemplo Práctico: Chatbot Simple

Tenemos un tutorial más completo en cómo crear un chatbot con Claude API.

import anthropic\n\nclient = anthropic.Anthropic(api_key="tu-key")\nconversation = []\n\nwhile True:\n    user_input = input("Tú: ")\n    if user_input.lower() == 'salir':\n        break\n    \n    conversation.append({"role": "user", "content": user_input})\n    \n    response = client.messages.create(\n        model="claude-3-5-sonnet-20241022",\n        max_tokens=1024,\n        system="Eres un asistente amigable.",\n        messages=conversation\n    )\n    \n    assistant_message = response.content[0].text\n    conversation.append({"role": "assistant", "content": assistant_message})\n    print(f"Claude: {assistant_message}")

Mejores Prácticas

  1. Usa system prompts: Define el comportamiento claramente
  2. Controla max_tokens: No pidas más de lo necesario
  3. Implementa retry: Para manejar rate limits
  4. Guarda contexto: Para conversaciones coherentes
  5. Valida respuestas: La IA puede equivocarse
