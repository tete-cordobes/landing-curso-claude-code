Claude Code para Principiantes: Guía Paso a Paso

¿Nuevo en Claude Code? Esta guía te lleva desde la instalación hasta tu primer proyecto completo. Aprende a programar con IA desde cero.

Bienvenido a Claude Code

Si estás empezando con Claude Code, esta guía es para ti. Te llevaré paso a paso desde la instalación hasta crear tu primer proyecto completo usando inteligencia artificial.

No necesitas experiencia previa con IA. Solo conocimientos básicos de programación. Y si querés ir más allá, el curso de Claude Code te lleva a nivel avanzado.

¿Por Qué Aprender Claude Code?

  • Multiplica tu productividad: Tareas de horas en minutos
  • Aprende mientras trabajas: Claude explica su código
  • Menos bugs: La IA detecta errores comunes
  • Documentación automática: Nunca más código sin documentar

Requisitos Previos

Lo que Necesitas

  • Computadora con macOS, Linux o Windows
  • Conexión a internet
  • Conocimientos básicos de terminal
  • Saber algo de programación (cualquier lenguaje)

Lo que NO Necesitas

  • Experiencia con IA
  • Conocer modelos de lenguaje
  • Ser experto en programación

Paso 1: Instalar Node.js

Claude Code requiere Node.js versión 18 o superior.

En macOS

# Con Homebrew\nbrew install node\n\n# Verificar instalación\nnode --version

En Linux (Ubuntu/Debian)

sudo apt update\nsudo apt install nodejs npm\nnode --version

En Windows

  1. Descarga el instalador de nodejs.org
  2. Ejecuta el instalador
  3. Abre PowerShell y verifica: node --version

Paso 2: Instalar Claude Code

npm install -g @anthropic-ai/claude-code

Verifica la instalación:

claude --version

Paso 3: Obtener API Key

Necesitás una API key de Anthropic. Tenemos un tutorial completo de Claude API con todos los detalles.

  1. Ve a console.anthropic.com
  2. Crea una cuenta o inicia sesión
  3. Ve a "API Keys"
  4. Crea una nueva key
  5. Cópiala (solo se muestra una vez)

Paso 4: Configurar API Key

macOS/Linux

# Temporal (solo esta sesión)\nexport ANTHROPIC_API_KEY="tu-key-aqui"\n\n# Permanente (añadir a ~/.bashrc o ~/.zshrc)\necho 'export ANTHROPIC_API_KEY="tu-key-aqui"' >> ~/.zshrc\nsource ~/.zshrc

Windows PowerShell

$env:ANTHROPIC_API_KEY="tu-key-aqui"

Paso 5: Tu Primera Sesión

Crea una carpeta para tu proyecto y entra en ella:

mkdir mi-primer-proyecto\ncd mi-primer-proyecto\nclaude

¡Ya estás dentro de Claude Code!

Comandos Básicos que Debes Conocer

Antes de tu primer proyecto, aprende estos comandos. Tenemos una guía completa de 10 comandos esenciales.

  • /help - Ver todos los comandos
  • /clear - Limpiar conversación
  • /diff - Ver cambios propuestos
  • /undo - Deshacer último cambio

Tu Primer Proyecto: Lista de Tareas

Vamos a crear una aplicación de lista de tareas paso a paso.

Paso 1: Pedir la Estructura

Escribe en Claude Code:

Crea una aplicación de lista de tareas (todo list) en\nJavaScript con Node.js. Quiero poder:\n- Añadir tareas\n- Marcar como completadas\n- Eliminar tareas\n- Ver todas las tareas\nUsa la terminal como interfaz.

Claude creará los archivos necesarios.

Paso 2: Revisar y Probar

¿Qué archivos has creado? Explícame la estructura.

Claude te explicará cada archivo y su propósito.

Paso 3: Ejecutar

/run node index.js

Paso 4: Mejorar

Añade la funcionalidad de guardar las tareas en un\narchivo JSON para que persistan entre sesiones.

Errores Comunes y Soluciones

Tenemos una guía completa de errores de APIs, pero acá los más comunes:

"Command not found: claude"

Node.js no está en el PATH. Reinstala Node.js o añade manualmente.

"Invalid API Key"

Verifica que la key esté bien configurada:

echo $ANTHROPIC_API_KEY

"Rate limit exceeded"

Estás haciendo muchas peticiones. Espera unos minutos.

Integración con VS Code

Si preferís un entorno visual, podés usar Claude Code dentro de VS Code. Mirá nuestra guía de configuración con VS Code.

Mejores Prácticas para Principiantes

  1. Empieza pequeño: Proyectos simples primero
  2. Lee el código: No copies sin entender
  3. Pregunta "por qué": Claude puede explicar sus decisiones
  4. Usa /diff: Revisa cambios antes de aceptar
  5. Experimenta: No tengas miedo de probar cosas

  4. Hacer el curso completo para nivel avanzado
